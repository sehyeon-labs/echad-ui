# ECHAD

> Two Become One  
> 성경적 결혼의 의미를 담은 모바일 청첩장

</br></br>

## 1. 프로젝트 소개

**ECHAD**는 히브리어 *אֶחָד*에서 가져온 이름으로,  
“둘이 하나가 되다”라는 성경적 결혼의 본질을 담고 있습니다.

본 프로젝트는 React 기반의 **모바일 전용 청첩장 웹 애플리케이션**으로,
간결한 디자인과 직관적인 UX를 목표로 합니다.

</br></br>

## 2. 기술 스택

- **React**
- **Vite**
- **JavaScript (ES6+)** 또는 **TypeScript**
- **CSS / Tailwind CSS (선택)**
- **React Router (선택)**

</br></br>
